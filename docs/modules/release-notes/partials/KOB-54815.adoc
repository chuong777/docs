== iOS device connectivity

- iOS devices no longer drop their connection when deviceConnect mounts the Developer Disk Image. Previously, a successful mount reset the device connection, and the device had to reattach before it was usable again.

// REVIEWER NOTE: Verified by QA on macOS 26.2, 26.3.1, and 27.0, on hosts both with and
// without usbmux redirection, so the fix is not specific to one host configuration.
// Direct before/after on a single host running 20 devices: the same 12 mounts produced 12
// connection resets before the change and 0 after, with a service refresh in place of each
// reset. Two resets remain in the after window, but both are the failure-recovery path
// rather than this defect, which fired on mount success.
//
// REVIEWER NOTE: The ticket does not record how long a device was unavailable after the
// old reset, or whether other devices on the same host were affected. The bullet is
